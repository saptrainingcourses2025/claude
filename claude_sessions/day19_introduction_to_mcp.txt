  How the number was computed (and a caveat to flag):

  The deployed Vacations table has budget and traveller_ID but no FK to 
  Destinations. Both tables join only through Travellers. So a vacation's budget
   can't be assigned to a single destination directly. The query splits each
  vacation's budget evenly across that traveller's destinations:

  attributed_cost = SUM( vacation.budget / count(traveller's destinations) )
